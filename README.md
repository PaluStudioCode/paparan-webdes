# Rancangan Modul Sistem Informasi & Website Operasional Desa

Repository ini berisi dokumen spesifikasi fungsional dan teknis untuk **Sistem Informasi & Website Operasional Kantor Desa** (berbasis **2 Role Pengguna**, **Master Data Kependudukan**, **4 Modul Operasional Utama**, dan **Portal Halaman Publik Desa**).

## 📄 Daftar Dokumen
- **[index.html](./index.html)** — Halaman Web Presentasi Interaktif (Otomatis merender `modul-sistem-desa.md` untuk GitHub Pages).
- **[modul-sistem-desa.md](./modul-sistem-desa.md)** — Dokumen Spesifikasi Utama Modul Sistem Operasional & Website Desa.
- **[rencana_penyempurnaan_modul_desa.md](./rencana_penyempurnaan_modul_desa.md)** — Catatan Hasil Review & Penyempurnaan Sistem.

## 🌐 Cara Mengaktifkan Website Presentasi di GitHub Pages
1. Upload/Push seluruh isi folder ini ke repository GitHub Anda.
2. Buka tab **Settings** pada repository GitHub Anda.
3. Pilih menu **Pages** di sebelah kiri.
4. Pada bagian **Build and deployment > Branch**, ubah dari `None` menjadi **`main`** (folder `/ (root)`), lalu klik **Save**.
5. Tunggu sekitar 30–60 detik, lalu buka tautan GitHub Pages yang muncul (contoh: `https://username-anda.github.io/nama-repo/`).
